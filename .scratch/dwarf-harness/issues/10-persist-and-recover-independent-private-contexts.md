## Acceptance criteria

- [x] One execution session owns distinct context memory/handoff/transcript/continuation and scratch; switching contexts never imports private state.
- [x] Durable private bytes precede revision record; mismatches block/report on restart and expected-revision concurrent writes refuse stale state.
- [x] Current-authorized immutable command receipts survive restart and same-ID replay; interrupted operations never imply effect success.
- [x] Context, memory, handoff and receipt records change only through producer-owned typed Core transitions that bind actor, context, operation and target, check expected version and current authority, publish required private bytes and a bounded replay-complete event group through the existing sequencer, then update rebuildable authorized projections before acknowledging; no caller writes these records directly, appends ad hoc state or keeps separate persistence, projection or restart hooks.
- [x] Deleting or rebuilding an optional projection cache loses no committed state, and rebuilding state never dispatches work.

## Answer

Ticket 10 is built, reviewed and on `main`. Core's private-state service, `internal/core/agents`, registers an agent with its one execution session and its general context, creates work contexts, and keeps each scope's private slots: the agent's instructions and memory, and each context's memory, handoff, transcript and continuation. A write names its agent, its context and the revision it expects. Core publishes the new bytes as durable content-addressed objects, commits one ledger group that ends in an immutable receipt, writes the Markdown files and updates its in-memory projection, and only then acknowledges. A stale expected revision is refused without writing anything. A retry under the same command ID returns the original receipt, and a changed request under that ID is refused. At restart, Open rebuilds every head and receipt from the ledger alone and verifies every selected object and Markdown file. It completes and reports a Markdown file left behind its committed revision, blocks a scope on foreign bytes or a missing or corrupt object, and appends and starts nothing. Scratch bindings are read from C2's records and never created. The service writes F3-10 as the project manager froze it (D139). Its surface is the owner's: there is no agent entry point, which ticket 11 adds with its grants. [B31](../../../docs/DECISIONS.md#b31-c3-the-private-state-service-ticket-10) records the design as ruled, the reading of Core's "blocks/reports rather than guessing", the project manager's answers during the build, the stand-in reviews, the build advisor's verification of them and the service's limits. The rows ran on one Windows machine, and CI run 8, on d99cb60, passed on Windows, Linux and macOS.
