# Contracts between roadmaps

**Status:** each contract's version and status are in the [register](#register) below, and each step's on the [status board](ROADMAPS.md#status-board). This register implements D40; these boundaries are design entries, not a freeze or permission to build. A contract's producer owns its schema, and consumers build against it only after it is frozen (D40; since D125 the project manager freezes a completed slice).

## What a contract is

- A Go package that uses only the standard library, under `contract/` in the root module (D45): `contract/ledger` holds `ledger-format` and `ledger-reader`; `contract/ledger/appender` holds the restricted `ledger-appender`; `contract/launcher` holds `launcher-protocol`; `contract/module` holds `context-module`; and `contract/law` holds `law-format`. Golden samples live in `contract/<name>/testdata/`.
- Golden sample files for every version of every record or message type it defines. Tests check the package against them, so a change made without a decision entry fails the check.
- An entry in the register below.

## Rules

| State | Who changes it | How |
|---|---|---|
| *Draft* | The owning step | Freely |
| *Frozen* | The project manager freezes a completed slice once the build advisor has approved it (D125; the owner before) | By addition only: new optional fields, new types, new type versions with upgraders |
| Breaking change to a frozen contract | Owner | A decision entry listing every step it affects; consuming roadmaps update those steps' status |

Freezing is the moment another roadmap's agent may start building against the contract (D20). Record each freeze as a decision entry and update the version and status columns below.

## Producer-ready family freezes (B2)

C1's first catalogue freeze owns framing, shared identity and only specified C1 records. Later operational families are versioned additions, never a second database or ledger. A freeze records event type/version, payload-specification owner, implementing producer, permitted appender caller, consuming capability, privacy class, replay-essential fields and a golden sample. Schema availability does not claim that a producer is operational. Core C2 owns the single policy-activation transition/manifest and its event; U1.L owns law meaning, C4 owns required-check evidence, and C1 owns event encoding. C7/C1 must separately specify the replaceable/bounded presentation snapshot/checkpoint and retry mechanism within Core's existing storage discipline; that mechanism neither appends every cosmetic edit forever nor compacts retained operational history.
