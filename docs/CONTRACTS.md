# Contracts between roadmaps

**Status:** each contract's version and status are in the [register](#register) below, and each step's on the [status board](ROADMAPS.md#status-board). This register implements D40; these boundaries are design entries, not a freeze or permission to build. A contract's producer owns its schema, and consumers build against it only after the owner freezes it.

## What a contract is

- A Go package that uses only the standard library, under `contract/` in the root module (D45): `contract/ledger` holds `ledger-format` and `ledger-reader`; `contract/ledger/appender` holds the restricted `ledger-appender`; `contract/launcher` holds `launcher-protocol`; `contract/module` holds `context-module`; and `contract/law` holds `law-format`. Golden samples live in `contract/<name>/testdata/`.
- Golden sample files for every version of every record or message type it defines. Tests check the package against them, so a change made without a decision entry fails the check.
- An entry in the register below.

## Rules

| State | Who changes it | How |
|---|---|---|
| *Draft* | The owning step | Freely |
| *Frozen* | The owner freezes it | By addition only: new optional fields, new types, new type versions with upgraders |
| Breaking change to a frozen contract | Owner | A decision entry listing every step it affects; consuming roadmaps update those steps' status |

Freezing is the moment another roadmap's agent may start building against the contract (D20). Record each freeze as a decision entry and update the version and status columns below.

## Fortress and shared leadership additions (D89–D96)

The [feature specification](../.scratch/fortress-gui/spec.md) defines required behavior and FG01–FG22 native acceptance, retaining FG01–FG15 and adding shared-lifecycle, representative-motion and officer-outage cases. C3 owns runtime guards, task facts and service-loss state; C6 owns relationships, memory, publication and recipient-authorized succession evidence; C8 owns creation, shared Purpose/alignment approval, outage Corps operation and lifecycle cutover; C9 **backend** supplies pinned skill/workflow execution. C7 owns the standard-library projection/command/attach encodings and shared terminal/GUI progress and outage surfaces; C1 owns catalogue framing and golden samples for actual producer-ready records. Stage and owner-freeze each real family before consumption. No seventh contract, GUI ledger or speculative placeholder event is introduced.

Current presentation retains applied layout, exact appearance/tileset IDs, unfinished creation/build drafts and TODO progress together. Keep topology-review acknowledgement, pending placement and `through_seq` independent. Core durably commits version-checked layout/progress saves atomically before acknowledgement, using a producer-specified replaceable/bounded presentation snapshot/checkpoint mechanism in the existing Core storage discipline. Cosmetic undo/history is bounded to the GUI run and discarded on close; saved current state survives. Finite cosmetic retry retention must return the existing result within its supported scope and reject stale/expired commands rather than reapply them or require immortal per-edit history. This does not weaken retained append-only birth, alignment, Purpose, approval, publication, handover or retirement history.

Reconcile terminal-created topology and preserve partial work through restart, save failure and version conflicts without duplicate births, placements or paid first turns. Enforce functional construction standards only for Build TODO completion, including nonwaivable desks/stations and connections; optional size/decorative thresholds and explicitly previewed rearrangement cannot change work eligibility. A draft, saved plan, artwork or story mention is never an operational creation or authority input. Inspection and reattachment resume the same durable interview state without dispatching extra work.

Administrator projections may inspect all colony records and private memories, including both relationship perspectives, while provider credentials remain Core-held and absent from GUI payloads. Agent projections retain current recipient/context and D83 retired-history restrictions. Classifiers receive only their named agent's eligible evidence, not administrator-only knowledge; automatic coalesced refreshes use ordinary admission/accounting, never view-triggered calls. Revoked evidence cannot remain visible, and still-authorized stale labels must be marked outdated/updating. Task stockpiles distinguish waiting ready/blocked work from active workshops; rails/runners animate authorized facts without delaying them.

The exact presentation mechanism/schema versions, numerical bounds, migration/retry expiry behavior, relationship rubric and attenuation function/coefficients/encoding/cutpoints, service-loss/outage/stand-in/handover encodings, readiness/cutover mechanisms and terminal attach encoding remain producer work under D40. Prefer a suitable complete off-the-shelf native terminal only within the owner's approximately 5–10% overall-project integration/adaptation allowance; otherwise use the user-selected external default terminal, not a bespoke emulator. Historical terminal research is not adoption, an estimate or runtime qualification. Native terminal behavior, original art export/composition, crash durability, accessibility and workload capacity require real implementation evidence. C7 base retains its C3 dependency; C8 waits for C9 backend alignment capability, while GUI-E parity and GUI-F remain independent gates.

Any boundary still absent from the integrated C2 specification remains open rather than inferred from an index. No C2/C3/C4 implementation or accepted-promotion gate is claimed here.

The boundary is internal to Core; D52 does not introduce another Go contract package or freeze any entry above. C1's event catalogue and golden samples must agree with the approved specification, and any change to already-frozen event types follows D40. U1.L remains the sole source of D47's validation policy; Core C2 owns the activation transition while C4 supplies actual required-check evidence.
